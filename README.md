# AWS Solutions Architect Associate (SAA-C03) — Prep & Cheatsheets

My notes, topic deep-dives, and practice questions for the
**AWS Certified Solutions Architect – Associate (SAA-C03)** exam.

> Format: for each topic — short theory → key exam facts →
> common scenarios/gotchas → practice questions with explanations.

## How to use

1. Each topic is a numbered folder (`01-...`, `02-...`).
2. Each folder contains:
   - `README.md` — topic notes (theory + exam facts).
   - `questions.md` — practice questions with answers and explanations.
   - `diagrams/` — diagrams (when needed).
3. Create a new topic from the [`templates/topic-template.md`](templates/topic-template.md) template.

## About the exam (quick reference)

- **Code:** SAA-C03
- **Questions:** 65 (~15 unscored pretest questions)
- **Time:** 130 minutes
- **Passing score:** 720 / 1000
- **Format:** multiple choice (1 answer) / multiple response (2+ answers)
- **Exam domains:**
  | Domain | Weight |
  |--------|--------|
  | Design Secure Architectures | 30% |
  | Design Resilient Architectures | 26% |
  | Design High-Performing Architectures | 24% |
  | Design Cost-Optimized Architectures | 20% |
